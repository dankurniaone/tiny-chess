A chess engine in at most 4,096 bytes of Python. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8081 python3 main.py
```

## How it plays

0x88 board, negamax alpha-beta with iterative deepening to a fixed node budget (deterministic, no clock), transposition table, killer moves and history ordering, quiescence over captures, promotions and replies to checks, and an incremental evaluation: material plus formulaic piece-square terms, bishop pair and a king middlegame/endgame blend.
